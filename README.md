## What's inside [`alx-project-0x02/`](alx-project-0x02/)

- A shared `Layout` with `Header` and `Footer`
- **Posts** and **Users** pages that fetch from the [JSONPlaceholder](https://jsonplaceholder.typicode.com) API
- `PostCard`, `UserCard` and a `PostModal` for creating content
- Typed interfaces for every API response

## Run it

```bash
git clone https://github.com/Dwaynemaster007/alx-project-0x02-setup.git
cd alx-project-0x02-setup/alx-project-0x02
npm install
npm run dev
```
